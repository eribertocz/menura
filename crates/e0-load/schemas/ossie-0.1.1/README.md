# Apache Ossie 0.1.1 model schema

`osi-schema.json` is the official structure of the 0.1.1 model (E0B-1.1, MDL-1.1), copied
byte for byte from the Apache Ossie repository. It is embedded in the compiler at compile time
by `src/structure/schema.rs`, which records the same source.
